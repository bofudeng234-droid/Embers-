# 抖音视频元数据收集指南(用于 200 条 demo 数据集)

> 目标:在周三晚之前收集 ≥ 200 条视频的元数据。**不需要下载视频本体**,只需要 URL + 用户记忆描述。

## 最快的方法:每天 1.5 小时正常刷抖音 + 顺手存

### 步骤

1. 抖音 APP 内正常刷
2. 看到有意思的视频 → 右下角 **分享 → 复制链接**
3. 切到一个备忘录(Apple Notes / 飞书文档 / 微信文件传输助手),粘一行
4. **顺手记一句"我为什么停下来看了它"**(这是黄金数据)— 不超过 10 个字

### 备忘录示例

```
https://v.douyin.com/abc123/  猫在扫地机器人上叫
https://v.douyin.com/def456/  收纳教程,叠衣服那段
https://v.douyin.com/ghi789/  讲 AI 创业第一年的心得
https://v.douyin.com/jkl012/  那个戴帽子的小姐姐做饭
...
```

**关键技巧:** "我为什么停下来"的描述就是后面 query 的训练数据。这些自然语言描述就是 demo 时输入搜索框的 query 原型。

## 数据多样性配比(建议)

为了 demo 时不同类型 query 都能命中,刻意刷不同类目:

| 类目 | 建议条数 | 用途 |
|---|---|---|
| 搞笑 / 萌宠 | 50 | 模糊回忆场景多 |
| 教程 / how-to(收纳/烹饪/装修等) | 40 | 演示"那段技巧在 2:14" |
| 知识 / 科技 / AI 相关 | 40 | 演示理性搜索 |
| 美食 | 30 | 视觉记忆强 |
| 生活记录 / vlog | 20 | 演示"那天我刷到的" |
| 商品 / 种草 | 20 | 演示"看见即买"延伸场景 |
| **总计** | **200** | — |

## 入库:CSV 准备(周四前)

把备忘录的内容整理到 `data/videos.csv`,字段:

```csv
id,url,title,caption,hashtags,duration_sec,watched_at,notes
```

- `id`:v001 - v200,自增
- `url`:抖音分享链接
- `title` / `caption` / `hashtags`:从抖音页面公开元数据手抄或脚本抓
- `duration_sec`:估算即可,精度无所谓
- `watched_at`:模糊的"那天那个时间"——用 ISO8601 格式
- `notes`:**你刚才在备忘录写的那句"我为什么停下来"——这是最重要的字段**

## 偷懒法 · 用脚本抓 caption(可选)

抖音公开分享页有 og:description,可以用一行命令批量抓:

```bash
# 在脚本里实现,赛前 1 天再说,不是 must
curl -sL "https://v.douyin.com/xxx/" | grep -oP 'og:description.*?content="\K[^"]+' 
```

**但 v0.1 阶段手动收集 200 条够用,不要在抓取上浪费时间。**
